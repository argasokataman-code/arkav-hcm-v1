# CSS Components Cheat Sheet

Dokumen ini berlaku untuk layer `frontend-gateway` (UI/presentation layer).

## Tailwind version

- `tailwindcss`: `^4.0.0`
- `@tailwindcss/vite`: `^4.0.0`

Template saat ini banyak menggunakan class Bootstrap-style + custom utility.
Cheat sheet ini dipakai sebagai referensi komponen UI selama transisi microservice.
